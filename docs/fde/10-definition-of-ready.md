# Definition of Ready (DoR)

Before an enterprise customer quote flow implementation sprint begins, the following inputs must be formally validated and locked:

- [x] **1. Territorial Scope Approved:** Target country codes and postal code regular expressions locked by the Underwriting committee.
- [x] **2. Actuarial Formulas Frozen:** Multiplier tables for property type, occupancy, floor area, construction era, claims history, and deductibles signed off by Chief Actuary.
- [x] **3. Data Classification Signed:** Data fields cataloged as Public, Internal, Confidential, or Restricted PII.
- [x] **4. Mandatory Consent Text Approved:** Legal & Compliance approved wording for GDPR Article 6/7 data processing declaration.
- [x] **5. Architecture Topology Selected:** Formal selection between Hosted SaaS (EU) or Customer VPC (Self-Hosted).
- [x] **6. Non-Functional Criteria Established:** Performance target ($<200\text{ ms}$ p95), session TTL ($3600\text{ s}$), and uptime target ($99.9\%$).
